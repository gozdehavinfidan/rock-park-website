# Rock Park — website

Static brand site for Rock Park, a desert mineral & crystal wholesale warehouse.
Night-museum design on Material Design 3 tokens, a procedural Three.js amethyst cluster and GSAP scroll motion. No build step.

## Run locally
Double-click `start.bat` (Windows), or:

```bash
cd site
python -m http.server 8080
```

Then open http://localhost:8080/.

## Structure
- `site/` — the website (published to GitHub Pages by `.github/workflows/pages.yml`)
  - `css/tokens.css` — M3 color roles (generated by `tools/make_tokens.mjs`), type, shape and motion tokens
  - `js/main.js` — navigation, filter, quick-view dialog, inquiry form (works without animation)
  - `js/motion.js` — GSAP scroll choreography
  - `js/crystal.js` — Three.js hero crystal, loaded on first interaction
  - `vendor/` — GSAP 3.13 and Three.js r170, self-hosted; `assets/fonts/` — Fraunces & Inter (SIL OFL)
- `tools/process_images.py` — crops, grades and exports photos from the raw originals (kept out of the repo)

## Before launch
- Replace the `[PHONE]`, `[EMAIL]`, address and hours placeholders in `site/index.html`.
- Set the real inbox in `CONTACT_EMAIL` in `site/js/main.js`.
- Prices are intentionally never shown on the site.
