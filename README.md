# Rock Park — website

Static site for Rock Park, a crystal & mineral shop at 1270 W Main St, Quartzsite, AZ 85346.
Night-museum design on Material Design 3 tokens with GSAP scroll motion. No build step.

## Run locally
Double-click `start.bat` (Windows), or:

```bash
cd site
python -m http.server 8080
```

Then open http://localhost:8080/.

## Structure
- `site/` — the website (published to GitHub Pages by `.github/workflows/pages.yml`)
  - `css/tokens.css` — M3 color roles (generated by `tools/make_tokens.mjs`), type, shape and motion tokens
  - `js/main.js` — navigation, filter, quick-view dialog (works without animation)
  - `js/motion.js` — GSAP scroll choreography
  - `vendor/` — GSAP 3.13, self-hosted; `assets/fonts/` — Fraunces & Inter (SIL OFL)
- `tools/process_images.py` — crops, grades and exports photos from the raw originals (kept out of the repo)

## Before launch
- Replace the `[PHONE]` and hours placeholders in `site/index.html` (hero and Visit section).
- When the Instagram account exists, turn the "Instagram · coming soon" line in the Visit section into a link.
- Prices are intentionally never shown on the site.
